# Pin a space to the taskbar

When a space opens, its window blinks once and gets its own button on the Windows taskbar, with an icon in the
space's colour. (Plain VS Code windows all share one blue button.)

### To pin it

1. Open the space.
2. On the taskbar, **right-click the space's button**.
3. Choose **Pin to taskbar**.

From then on, clicking the pin opens that space, and while it's open the window sits on its pin.

### Good to know

- Renaming a space keeps its pin working.
- If you delete a space, unpin its button too (right-click > **Unpin from taskbar**).
- If a space's window ever lands on the plain VS Code button instead, run
  **Vibespaces: Give This Window Its Own Taskbar Button** (Ctrl+Shift+P, then type it).
